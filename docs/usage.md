# APK Push 使用说明

[返回项目首页](../README.md)

## 连接与推送

1. 在手机安装 APK Push。
2. 将手机与设备接入同一可互访局域网，设备可通过网线接入。
3. 在设备开发者选项中开启“网络调试 / 网络 ADB”，记录设备 IP 和实际连接端口；常见端口为 `5555`。
4. 点击“选择设备”自动搜索，选择目标设备；也可手动输入 IP 和端口。设备管理面板中的“连接设备”可单独检查连接。
5. 点击“选择安装包”，从文件或下载库选择；也可切换“应用”搜索并下载。下载项的“推送”按钮将安装包带入推送页。核对应用与设备后，点击“推送并安装”，首次连接在目标设备接受 `APKPush@android` 的调试授权。
6. 保持应用在前台，等待传输、安装和版本核验完成；期间可切换底部标签。成功后可选择“在设备上打开”，或在右上角“更多”中选择“再次安装”。

自动搜索使用可用的 Wi-Fi 与有线网络，优先探测已保存设备的实际端口。VPN 或系统禁止绑定 Wi-Fi 时，探测使用系统路由，扫描范围仍由局域网地址决定。主动扫描先检查本机所在 `/24`，再覆盖实际子网内最多 `/22` 范围的 `5555` 端口；较小子网按实际范围检查。搜索至少监听 15 秒，探测未结束时最长 45 秒；本机 `/24`、已保存和广播目标超时后补扫一次。mDNS 支持传统 ADB、无线调试连接与配对服务，并提供解析超时和重试。扫描排除本机、网络与广播地址，使用 ADB 握手识别服务，不发送授权密钥。未保存且未广播的自定义端口仍需手动添加，离开设备选择面板停止搜索。

**只开启 USB 调试不代表网络端口已经开放。** 只有 USB ADB 的设备，需要先通过已有 USB 调试连接执行 `adb tcpip 5555`；设备重启后可能需要重新开启。本工具不能远程替设备开启尚未开放的调试服务。

配对码端口与连接端口用途不同。发现的 TLS 无线调试设备会标记“需配对”，当前版本不能直接连接安装。传统 TCP ADB 未使用 TLS，应在可信局域网内使用。

## 安装行为

- 同包名、同签名应用使用覆盖安装，包管理器负责保留应用数据。
- Play 拆分包通过一个 `pm install-create / install-write / install-commit` 会话一起安装，上传每个文件后才提交。
- 签名不匹配、版本降级、SDK / ABI 不兼容、空间不足和厂商策略拒绝均显示错误原因。
- 应用不会自动卸载原应用、自动降级或默认授予运行时权限。
- 上传达到 100% 后仍需等待设备安装与版本核验。安装期间显示不确定进度。
- 切换底部标签或旋转屏幕会保留当前任务。离开应用或锁屏会停止手机等待，设备上已经开始的安装可能继续。
- 安装提交后的超时、断线或取消显示“结果待确认”。点击“核对结果”查询原任务的包名、版本与设备用户；用户在设备确认任务结束后，可以清理任务记录并重试。
- 上传阶段未提交的遗留文件在下次连接同一设备时清理。设备序列号与原记录不符时保留记录，并提示检查目标地址。
- 安装成功不保证应用适合目标设备的屏幕、输入方式或系统定制。

## Google Play 下载

- 搜索使用 Google Play 公开网页接口，下载使用 Aurora gplayapi 4.0.0 的匿名设备会话；无需提供 Google 账号或密码。手机网络必须能访问 Google 服务。
- 下载机型默认本机，在 Google Play 搜索框下方查看和选择。选择面板支持品牌、型号、API、Android 版本、架构和“本机”“电视”等关键词即时过滤，多个词以空格分隔，支持清除搜索；标题和搜索框固定，结果独立滚动。
- 机型来自本机实时参数和 gplayapi 4.0.0 内置的 23 个设备配置，不是全部 Android 机型目录。配置包含系统、架构、屏幕、功能和共享库等参数；电视可选 BRAVIA VU2（API 30、32 位 ARM），该配置不代表所有索尼电视。推送前仍检查实际 APK 的 SDK 和 ABI。未完成的下载使用任务已保存的机型。
- 支持免费应用的主 APK 及拆分 APK。Google Play 服务等运行依赖由目标设备提供，允许下载应用本身的 APK。付费、地区或设备限制、需要账号授权、OBB、Play Asset Delivery 和配套共享库均明确提示限制；共享库提示包含库包名，当前不支持自动下载和安装这些库。
- 每个文件使用 HTTPS 下载并校验 Play 提供的哈希及长度；本地记录另存 SHA-256，直接推送时在传输过程中复核；使用解包缓存时在准备阶段复核。网络中断保留半成品，主动取消删除未完成文件。
- 完整下载通过 Android MediaStore 保存在公共 `Download/APK Push`，文件管理器可见，卸载或清除 APK Push 数据后文件仍保留。点击下载项可查看完整保存位置或安装到本机，右侧“推送”将安装包带入推送页。左滑下载项可删除；“删除”操作需点击“确认”，确认后同时删除公共文件，无全盘存储权限。
- 应用启动时将私有目录中的完整下载保存到公共目录，校验公共文件后清理原 APK，下载标识与机型保持不变。空间不足或写入失败时保留原文件。下载索引、未完成任务和续传文件保存在私有目录；独立 APK 推送优先直接读取公共文件，并在传输时校验 SHA-256；源文件变化或校验失败时不提交安装。拆分包与兼容路径准备临时缓存，切换安装包或重启应用时清理。保存以及需要缓存的推送路径预留一份安装包大小及 32 MiB 空间。
- 独立包保存为 `.apk`；拆分包保存为含全部 APK 的 `.apks` ZIP，可由支持拆分包的安装器使用，APK Push 可从下载库直接推送。当前文件导入入口不接受外部 `.apks` / `.xapk` / `.apkm`。清除应用数据或卸载会删除下载库索引，重新安装后不会自动导入保留的公共文件。
- 最多同时下载 3 个应用，其余按加入顺序排队；暂停、取消、失败或完成后，空闲名额交给等待任务。手动继续或重试的任务加入队尾。同一应用和机型的重复点击复用现有任务，修改下载机型只影响之后加入的任务。
- 下载由 `dataSync` 前台服务运行，离开应用、划掉最近任务或锁屏后继续；页面与通知栏提供每项任务的暂停、继续、重试和取消，通知还提供下载库入口。搜索结果中的任务按钮可直接定位对应下载，结果列表末尾显示任务概况；下载库先显示完整安装包，再逐项显示未完成任务的图标、状态和进度。
- 更新检查使用与下载相同的机型接口，比较包名、机型和 versionCode；版本文字不参与大小判断。同一进程内同一应用与机型的自动检查间隔至少 15 分钟，手动检查可立即重查。失败保留已知版本与安装包，菜单手动检查可显示失败原因；离开应用取消版本查询，下载继续运行。原机型不可识别时不使用其他机型的版本代替。
- 下载中、暂停或失败时均可搜索其他应用，查看、推送或删除已完成的下载。搜索与下载分别显示进度或错误，取消搜索不影响下载，取消某项下载不影响搜索或其他任务；新搜索只保留最新查询的结果。
- 下载队列、每项机型快照与进度持久保存在私有目录。暂停保留未完成文件，点击“继续”恢复；断网或下载失败后保留任务，等待手动点击“重试”。断网时等待中的任务也保留并等待重试，恢复网络或重新打开应用不会自动开始下载。全部任务暂停、失败或完成取消后停止后台下载服务并释放唤醒锁。
- 每次恢复重新获取下载链接，核对版本、机型、文件名、长度与哈希；一致时复用完整分包，并对半成品发送 HTTP Range 请求。服务器忽略 Range 时重新下载该文件；范围或哈希无效的文件会丢弃。版本或文件集合变化时重新下载整套文件。
- 系统回收进程、应用异常退出、强行停止或设备重启后，重新打开应用显示保留的任务，点击“重试”或“继续”后恢复下载。取消删除未完成文件和任务记录；已保存的完整文件会复用，避免重复入库。
- 搜索和向设备推送仍在前台执行，离开应用或锁屏会停止等待；下载后台服务仅承载 Google Play 下载。
- 第三方接口可能随 Google Play 变化而失效；部分应用运行需要 Google 服务、账号或额外内容。APK Push 与 Google 无隶属关系。
- gplayapi 是 Aurora OSS 的第三方开源客户端库，不是 Google 官方开源下载 SDK，也不提供无限请求额度承诺。Google 服务可能返回 HTTP 429、要求账号授权或限制应用可用性；当前应用按错误提示处理，下载由用户手动重试。应用最多并发下载 3 项，单项上限为 2 GiB。
